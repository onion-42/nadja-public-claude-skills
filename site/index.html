Team Skills.

A Claude Code plugin marketplace with two plugins. team holds workflow skills and agents that help you spend tokens well and finish tasks without starting new ones. neurodivergent is an opt-in set of comfort tools for ADHD, autistic and dyslexic users.

Install

Run these in Claude Code. The second plugin is optional and works best alongside the first.

/plugin marketplace add onion-42/nadja-public-claude-skills
/plugin install team@team-claude-skills
/plugin install neurodivergent@team-claude-skills

Or copy a single item with the command on its card; run it from the root of a clone (git clone https://github.com/onion-42/nadja-public-claude-skills).
