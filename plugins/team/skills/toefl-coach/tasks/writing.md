## Build a Sentence

Shape: one person says a line; the reply is a sentence or question with the word chunks shuffled.
Arrange ALL chunks into one grammatical sentence. Some sets contain one extra chunk that does not fit
(the real test may do this — guess); say which chunk is extra.
Timing for practice: about 35 seconds per item (23 min section ÷ 12 items, minus the long tasks; guess).

### BS-1
1. A: "Did you finish the lab report?" — B: [ yet / haven't / the results / I / analyzed ]
   Answer: I haven't analyzed the results yet.
2. A: "The library closes early today." — B: [ what / it / do you / closes / know / time ] ?
   Answer: Do you know what time it closes?
3. A: "I missed the seminar." — B: [ the slides / send / can / to you / I / later ]
   Answer: I can send the slides to you later.
4. A: "Is the shuttle running?" — B: [ been / since / it / cancelled / has / Monday / was ]  (one extra)
   Answer: It has been cancelled since Monday. Extra: "was".
5. A: "Which room is the exam in?" — B: [ where / I / is / the exam / wonder / held ]
   Answer: I wonder where the exam is held.

### BS-2
1. A: "Why are you late?" — B: [ the bus / because / broke down / was / I / late ]
   Answer: I was late because the bus broke down.
2. A: "Have you met the new advisor?" — B: [ yet / not / had / I / a chance / have ]
   Answer: I have not had a chance yet.
3. A: "The deadline moved." — B: [ when / you / did / it / find out / changed ] ?
   Answer: When did you find out it changed?
4. A: "Can I borrow your notes?" — B: [ as long as / them / you / bring / back / tomorrow ]
   Answer: As long as you bring them back tomorrow.
5. A: "Is this seat free?" — B: [ someone / is / I / think / sitting / here / it ]  (one extra)
   Answer: I think someone is sitting here. Extra: "it".

### BS-3
1. A: "How was the conference?" — B: [ more / it / useful / expected / than / was / I ]
   Answer: It was more useful than I expected.
2. A: "Who is giving the lecture?" — B: [ who / sure / I'm / is / not / speaking ]
   Answer: I'm not sure who is speaking.
3. A: "The printer is broken again." — B: [ fixed / should / we / have / it / get ]  (one extra)
   Answer: We should get it fixed. Extra: "have".
4. A: "Did the experiment work?" — B: [ to / we / have / repeat / it / will ]
   Answer: We will have to repeat it.
5. A: "Where should I submit the form?" — B: [ whether / the office / I / online / accepts / it / don't know ]
   Answer: I don't know whether the office accepts it online.

## Write an Email (7 min)

Shape: a short situation + three things the email must do. Write to the named person.

Template (show it under every Email task; `timer.ps1 -Task Email` speaks these marks):

| Time | Part | Starter phrase |
|---|---|---|
| 0:00–0:30 | Read the 3 points | — |
| 0:30–1:00 | Greeting + purpose | Dear …, I am writing about … |
| 1:00–5:30 | Points 1, 2, 3 — 2 sentences each: fact + detail | Unfortunately, … This matters because … / Could you please … / Alternatively, … would work for us. |
| 5:30–6:00 | Polite closing | Thank you for your help. Best regards, <your name> |
| 6:00–7:00 | Check | All 3 points there? |

### EM-1
You booked a group study room in the university library for Thursday 14:00–16:00. Today you received
a message that the room is closed for repairs that day. Write an email to the library manager, Ms. Harris.
In your email:
- explain your situation and why the booking matters to your group;
- ask for a solution;
- suggest one alternative that would work for you.

### EM-2
Your professor, Dr. Okafor, has asked students to give feedback on the new online quiz system used in the
course. You found some parts helpful and some parts frustrating. Write an email to Dr. Okafor.
In your email:
- describe one thing that worked well;
- describe one problem and how it affected you;
- recommend a change.

### EM-3
A classmate, Daniel, missed two weeks of class because he was ill. He emailed you to ask how he can catch up
on a group project that is due in ten days. Write a reply to Daniel.
In your email:
- tell him what the group has finished so far;
- explain what part he could take on;
- propose a time to meet.

## Write for an Academic Discussion (10 min)

Shape: a professor's question + two short student posts. Write your own post: state your view, support it,
and react to at least one classmate.

Template (show it under every Discussion task; `timer.ps1 -Task Discussion` speaks these marks):

| Time | Part | Size | Starter phrase |
|---|---|---|---|
| 0:00–1:00 | Read, pick ONE side | — | — |
| 1:00–2:00 | 1. View | 1 sentence | In my view, … is better, because … |
| 2:00–5:00 | 2. Reason + example | 2–3 sentences | The main reason is … For example, … |
| 5:00–7:00 | 3. React to a classmate | 1–2 sentences | I agree with … that … / … has a point, but … |
| 7:00–8:00 | 4. Conclusion | 1 sentence | So, … |
| 8:00–10:00 | Check | — | Verb forms: he makes / doesn't make |

### AD-1 — Public policy class
**Professor Lin:** Many cities are considering making public transport free for everyone, paid for by taxes.
Supporters say it reduces traffic and pollution. Others say the money would be better spent improving
service quality. Which approach do you think is better, and why?
**Amara:** Free transport is the fastest way to change habits. If the bus costs nothing, people will leave
their cars at home, and traffic will drop.
**Tomas:** Free is useless if the bus comes every 40 minutes. I'd rather pay a small fare and have reliable,
frequent service. Quality is what makes people switch.

### AD-2 — Education class
**Dr. Reyes:** Some universities now allow students to use AI tools when writing essays, as long as they
say how they used them. Others ban AI tools completely. Which policy do you support? Explain.
**Hana:** Banning AI is unrealistic. Students will use it anyway, so it's better to teach them to use it
honestly and well.
**Leo:** If AI writes part of the essay, the grade no longer shows what the student can do. A ban protects
fair assessment.

### AD-3 — Biology class
**Professor Adeyemi:** Some scientists argue that research funding should go mainly to basic science, where
the practical use is unknown. Others think funding should focus on applied research that solves current
problems, like disease. Where should most funding go?
**Sofia:** Applied research saves lives now. With limited money, we should fund what has a clear benefit.
**Kenji:** Many medical breakthroughs came from basic research no one thought was useful — like CRISPR from
studying bacteria. Cutting basic science would hurt applied science later.
