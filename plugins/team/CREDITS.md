# Credits — team plugin

Skills in this plugin that come from other projects. Everything not listed here is original to
this repository.

## `obra/superpowers` (MIT)

https://github.com/obra/superpowers — adopted with their upstream frontmatter
(`when_to_use`, `version`, `languages`):

- `systematic-debugging`
- `root-cause-tracing`
- `dispatching-parallel-agents`
- `testing-skills-with-subagents`
- `writing-skills`

## `affaan-m/everything-claude-code` (ECC, MIT)

https://github.com/affaan-m/everything-claude-code — marked `origin: ECC` in their frontmatter:

- `deep-research`
- `eval-harness`
- `strategic-compact`

## Anthropic `skill-creator` (Apache 2.0)

- `skill-creator` — Anthropic's skill-creator skill. Its Apache 2.0 licence ships unchanged in
  `skills/skill-creator/LICENSE.txt`.

## Tools used, not code copied

- `find-docs` calls the Context7 CLI (https://github.com/upstash/context7); the CLI is installed
  separately and keeps its own licence.
