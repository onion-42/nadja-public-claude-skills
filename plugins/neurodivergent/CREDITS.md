# Credits — neurodivergent plugin

## `output-styles/nd-friendly.md`
Paraphrases and adapts rules from two MIT-licensed output styles:
- `hseinmoussa/exo` — `output-styles/exo.md` @ b8a2bfb21fd7. Taken: answer first, literal language,
  explicit assumptions, confidence labels, one next action, Parked, completion block, choices capped at 5,
  scope instead of time, full depth, debug brake, first/last-line check.
- `assafkip/adhd-output-style` — `output-styles/adhd.md` @ 6aade4b4eb33. Taken: repeat context inline,
  dismissal rule, announce pivots, demand-free phrasing (the `soft` flag), specific feedback.

The flag system, `bionic`, `anchor` and `literal+` are original to this bundle.

## `skills/when-stuck`
Adapted from `obra/superpowers` (MIT). Changed: one-line inline fallbacks for techniques that are not installed.

## `commands/checkpoint.md`
From `affaan-m/everything-claude-code` (MIT), unchanged.

## Everything else
`nopanic`, `cho`, `goal`, `mini-reflection`, `notify`, `mode`, `pickup-handoff` are original to this bundle.
